# DRESSROOM

DRESSROOM is a self-contained fashion-game prototype with an animated intro and a Sims-inspired 3D character editor.

## Open locally

Open `index.html` in a modern browser. The intro is followed by the character studio in `studio.html`.

## Publish

This project is ready for GitHub Pages. Serve the repository from the root of the default branch.

## Notes

- No package installation or build step is required.
- The character editor uses WebGL when available and includes a software-rendered fallback.
- Saved looks stay in the current browser's local storage.
- The prototype contains no accounts, analytics, or uploaded personal data.
